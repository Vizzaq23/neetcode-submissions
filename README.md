Files are grouped by topic and problem, with separate numbered submissions:

```text
Data Structures & Algorithms/
```

Multiple submissions show iteration on a problem. Submission counts are not unique-problem counts, and this repository does not make a blanket claim that every saved attempt is optimal or accepted.

## How to use this repository

Open a problem folder to inspect its submissions. Most solutions target the platform's problem-specific function signatures and inputs; they are not standalone applications and there is no shared application build or test command.

This repository documents practice. My portfolio links to complete applications, project demos, and engineering case studies.
